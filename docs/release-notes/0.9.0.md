## 本版内容

**型号退役：点名名单，不再靠探活猜死活**

- 新增 `providers/workbuddy/retired.json` —— 按上游 id 点名退役，值写原因（下线公告 / 被哪一档接替）。恢复某条就删掉对应键，名单是唯一开关。
- 调整 `workbuddy_fetch_pricing.py` —— `load_retired()` 在骤降并回**之后**剔除名单内型号并打印条数；文件缺失或 JSON 损坏一律当作无退役项，只做减法。
- 修复 同步链路 —— 价格表不再被旧行撑大，`live_complete` 得以成立，面板已删除的 `cn:hy3` / `cn:hy3-x` / `cn:hy4free` / `cn:hy4-preview*` 走 stale 清理，从 `provider_config.json` 彻底删除。
- 修复 清单视图 —— `current-models.ps1` 的 billing_suspect 按同一名单过滤，已下线型号的历史扣费记录不再挂在「当前清单」上。

**命名：限时免费档与付费档同族**

- 修复 `abbreviate()` —— 剥掉 `-free` 后回查 `ABBR`，`cn:hy4flash-free` 由 `hy4Flash` 改为 `HY4-Flash-Free`。
- 修复 `family_key` —— 正则补上 `-free`，免费档与付费档归并到同一型号，不再被当成两个条目、也不再撞名。
- 调整 省钱组白名单 —— 失效的 `chat:cn:hy3-x` 换成 `chat:cn:hy4flash`（x0.03），`ABBR` 补 `hy4flash → HY4-Flash`。

## 本版对应的现象

2026-11-16 公告：Hy4 Flash 上线、11/16–11/30 限时免费；Hy4 限免结束；Hy3 端内下线。用户看到的却是面板免费组里还挂着 `HY3` 与 `HY4-Free`。

链条：面板只剩 20 条 → 骤降保护把 21 行旧价并回 → `pricing_ids(39) ⊉ live_ids(20)` → `live_complete=False` → 旧型号按「列表残缺，保留」留在配置。加 `--probe` 也救不了：网关对已下架型号照样回 200，`dead` 为空。

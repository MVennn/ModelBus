## 本版内容

**可视化控制台**

- 新增 控制台 —— `tools/console/` 独立进程，`pwsh tools/console/start-console.ps1` 起在 `127.0.0.1:7872`，8 页（总览 / 模型 / 价格 / 健康 / 流量 / 账号 / 日志 / 运维）一屏看住网关、目录、价格、流量与日志。
- 新增 17 条只读路由 —— 13 个 `/api/*`、`/healthz`、SSE 日志流与 `/api/actions/jobs`；写面只有 `POST /api/actions/reload`，只转发 zgate 的 `/admin/reload`，不启停任何进程。
- 调整 后台外壳 —— Tabler 1.7.4 单 CSS 本地离线（零 CDN / 零 npm / 零构建），设计规则是 Microsoft Fluent 2 令牌；手写静态资产 41,816 B，vendor 单文件 686,736 B 单独计。
- 优化 数据读取 —— `/health` 用 5s 服务端缓存合并多标签轮询（网关每次 `/health` 都会重读 alias map）；日志与请求明细只流式读尾部，27 MB 日志目录不再全量进内存。
- 修复 状态灯与写面兜底 —— 健康页 502 现在显示「网关不可达」、总览页在线不再恒显不可达；非预期异常返回统一 JSON 错误包，不再吐裸 HTML。
- 新增 文档 —— `docs/CONSOLE.md` 是控制台正本（页面清单、字段来源、验收口径），README 新增「可视化后台」与「文档」两段入口。

**DSH 主宿主改造**

- 调整 架构定位 —— 本仓从「给 ZCode 客户端写配置」改成「DSH 主宿主 + 各类 agent 共用模型供给与路由」，ZCode 降为兼容投影；配置路径、环境变量名、配置 schema 键与商标一字不动。
- 调整 脚本命名 —— `workbuddy_sync.py` / `workbuddy_probe.py` / `effective_body.js` / `qoder_sync.py` / `qoder_probe.py` / `qwen_sync.py` 换成中性名，旧的自造环境变量仍可读。
- 新增 `tools/agent_profiles.py` —— 以 `catalog/model_caps.json` 为唯一能力真源，为会话 / 子代理 / headless / 服务插件四类 profile 生成只读投影，不写任何现网配置。
- 调整 `tools/dsh_sync.py` —— 新增 `--source compat|dsh`（默认 compat 与改造前逐字节等价）与 `--export-inventory`（导出零凭据清单）。
- 调整 文档 —— 新增 `docs/DSH-FIRST.md` 作方向与批次正本，README / CONTRIBUTING / SECURITY / AGENTS 主语同步。

**zgate 自启与探活修复**

- 修复 自启 —— 收敛成单个计划任务 `\ModelBus-zgate-watchdog`（登录即拉起 + 每 1 分钟兜底双触发器），换版拉起与失败回滚统一走同一入口，不再有第二套拉起点法。
- 修复 探活 —— `sync-models.ps1` 探活请求体给足 `--max-tokens 256`，思考吃满预算的型号不再被误判成死型号。
- 修复 模型消失判定 —— 空 completion 判 SKIP，模型从清单里消失前先告警，不再静默删条。
- 修复 上游语义 —— `503 high demand` 这类「上游说自己忙」不再被软冷却埋一分钟；`400` 思考档位枚举不合法时剥掉该参数重发同一跳，不再把 INVALID_REQUEST 甩给客户端。
- 新增 逐跳观测 —— 每跳 `try / ok / busy / e5xx / silent / no_first_block` 计数进 `/health.hops`，串行链也能看出哪一跳最近不行；只做观测、不参与决策。
- 调整 竞速与流式 —— 竞速参数按跳取值、按链聚合；流式请求等上游响应头期间先回 200 + SSE 心跳，客户端不再提前判死。
- 调整 文档 —— `docs/ZGATE-LIFECYCLE.md` 等九篇按「单任务 watchdog」口径重写，新增 `docs/ROUTING-POLICY.md` 承载逐跳等待与判死规则。

**模型目录与价格同步**

- 新增 能力目录 —— `catalog/model_caps.json` 与 `tools/model_caps.py`：19 个模型的上下文 / 输出上限 / 图片 / 工具 / 档位逐条带出处，`python tools/model_caps.py --check` 可逐字段复核差异。
- 新增 上游取证链路 —— `tools/caps_upstream.py` 与 `catalog/upstream_caps*.json`，能力字段从上游规则推导，不再由通配规则兜成 1M / 128k。
- 调整 链长 —— `CHAIN_CAP` 给按次计费族设 3 跳上限，`Gemini-AIS` 从 7 跳收窄到 3 跳；被裁掉的跳仍能按老名字解析。
- 调整 推理档位 —— `model_alias.py` 与 `dsh_sync.py` 在别名合并与宿主投影里保活思考档位，不再被下游默认值盖掉。
- 调整 价格缓存 —— Qoder 刷新 `providers/qoder/cache/qd_prices.json`：`Qwen3.8-Max` 0.5 → 0.2、`Qwen3.8-Flash` 0.1 → 0.04，22:00 起夜间档生效。
- 调整 环境变量与依赖口径 —— `docs/SECRETS.md` 补 `GEMINI_API_KEY` / `HJM_API_KEY` 两条，`docs/TOOLS.md` 与 README 标明 `tools/model_stream_check.py` 需 PyYAML。

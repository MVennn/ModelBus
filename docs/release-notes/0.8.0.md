## 本版内容

**转发热路径：少解析、少分配**

- 新增 零分配 JSON 扫描 —— `parseBodyFacts` 一次扫出 `model` / `stream` / `reasoning_effort` / `thinking` / `tools`，替代过去六处各自 `json.Unmarshal` 同一份 body；旧函数签名保留，调用方零改动。
- 新增 字节级改写 —— `withModel` / `withStringField` 直接拼字节，不再 `map[string]any` 往返，也不再触发 `json.Marshal` 的 HTML 转义（`<` `>` `&` 保持原样，不再变 `\u003c`）。
- 新增 缓冲池 —— 32 KB 流式读缓冲走 `sync.Pool`，稳态下每请求不再新造一块短命对象。
- 调整 别名热加载 —— 热路径上每秒最多 `os.Stat` 一次 alias map（原先每请求都 stat），`/admin/reload` 后强制归零立刻重读。
- 调整 桥接解析 —— `internal/bridge` 不再为读 `stream` 把整份 body 二次反序列化，`messagesOf` / `toolsOf` / `rawMap` 合并成一次解析。
- 调整 `http.Server` —— 补 `ReadHeaderTimeout` 15s / `IdleTimeout` 120s / `MaxHeaderBytes` 1 MiB；**不设** `ReadTimeout` / `WriteTimeout`，否则长流式回答会被从中间掐断。

**可观测面：请求带号，指标外露**

- 新增 请求号 —— 客户端带 `X-Request-Id` 就沿用，否则生成 16 位十六进制；响应回写 `X-Zgate-Request-Id`，同一个 id 带给上游、写进收尾日志 `[req] …`、出现在慢请求样本里。
- 新增 跳头 —— 成功转发回写 `X-Zgate-Channel` / `X-Zgate-Model` / `X-Zgate-Attempt`（跨回落累计）/ `X-Zgate-Hop`，客户端只看响应头就知道命中哪条上游、前面失败过几次。
- 新增 `GET /metrics` —— Prometheus 文本：请求数、延迟直方图、链跳、别名版本、子进程 up、draining。
- 新增 `GET /admin/stats` —— 计数、分位延迟、状态码分布、最近慢请求（带请求号）、冷却与子进程状态。
- 新增 `GET /admin/routes` 与 `GET /admin/explain` —— 整张路由表（每跳带状态：`ready` / 冷却至几点 / 静默至几点 / 渠道关闭）与「这个名字最后打到哪」。
- 新增 `GET /admin/logs` 与 `GET /admin/pprof/*` —— 日志尾部（`?lines=` / `?filter=`，只回看末尾 512 KiB）与堆 / CPU / trace。
- 新增 `POST /admin/drain` —— 换版前先置 draining 并等手上请求走完（`?wait_ms=` 缺省 5s / 上限 30s），不再硬切正在流式输出的回答。
- 调整 `/v1/models` —— 带 `ETag`，`If-None-Match` 命中回 304、零 body；目录体按别名表版本缓存在进程内。

**安全与收尾**

- 调整 管理面鉴权 —— `/admin/*` 三道：回环来源 + `X-Zgate-Admin` 头 + 同源 `Origin`，配了 `adminToken`（或 `ZGATE_ADMIN_TOKEN`）再加常量时间口令比较。过去任意网页一个 `text/plain` POST 就能让网关重读配置。
- 调整 请求体上限 —— `/v1/*` 套 `http.MaxBytesReader`，缺省 32 MiB（`zgate.json` 可覆盖），超限 413；过去是无限读，一条几 GB 的 POST 能打满内存。
- 调整 优雅退出 —— 收到 `SIGTERM` 先置 draining（`/health` 与 `zgate_draining` 可见），此后响应带 `Connection: close`，客户端不再把请求复用给即将断开的连接。
- 调整 换版脚本 —— `tools/zgate-lifecycle/deploy-zgate.ps1` 停旧进程之前先 `POST /admin/drain?wait_ms=8000`；旧二进制没这个端点时回 404，脚本按原行为直接停。

**控制台**

- 新增 三条只读路由 —— `/api/routes`、`/api/stats`、`/api/metrics`，统一补管理头，旧二进制 404 归 `NOT_SUPPORTED` 降级（页面照常渲染，不 500）。
- 新增 两处视图 —— 总览「请求与延迟」卡片（RPS / 5xx 率 / p50 / p90 / p99 / inflight）、「路由表」页（按渠道分组的跳行 + 模型 → 链总表）；健康页附 Prometheus 原文，另加请求账本与慢请求表。
- 调整 reload 转发 —— `tools/console/actions.py` 补 `X-Zgate-Admin: 1`，配了口令再补 `X-Zgate-Token`；不带头的旧写法现在 403。

## 升级须知

- **必须换二进制**：`/metrics`、`/admin/*`、请求号、`ETag` 都是编译期落地的，`/admin/reload` 只能热加载策略 / 空闲窗口 / 上游 `base` 与 key。
- 手工 curl 管理面补 `-H "X-Zgate-Admin: 1"`；配了口令再加 `-H "X-Zgate-Token: $env:ZGATE_ADMIN_TOKEN"`。
- 控制台在旧网关上会自动降级显示「不可用 / NOT_SUPPORTED」，换完二进制自动出数，无需改代码。

**zgate 支持每跳自己的出口（分步代理链），地区受限的 403 自动换机场兜底跳；传输层瞬时失败重试同一跳。**

## 本版内容

**zgate 路由与链路**

- 新增 每跳出口 `chain[].proxy` —— alias map 的每一跳可带自己的出口：同一 upstream 可以在链里出现两次、只差出口；地区受限模型的 403（`unsupported_country…` / `RegionError`）现在会自动切到链上的机场兜底跳，不再原样返回给客户端。
- 修复 传输层瞬时失败 —— 机场对大包短暂黑洞（EOF / TLS 握手超时 / reset 等）先原地重试同一跳一次（300ms），一跳链不再直接 502；普通 5xx 不重试（上游可能已计费）。
- 修复 429 退避预算 —— 传输层重试与 429 退避分开计数，先传输失败过的请求也能吃到 700ms 就地退避，不再直接进 45s 冷却。
- 修复 空出口残留 —— 链上「机场跳后面跟直连跳」时直连跳不再沿用上一跳的机场出口（空值即直连）。
- 修复 504 冷却对齐 —— chat 链路径收到 504 也把该跳冷却 5 分钟，与桥接路径一致；静默僵死的上游不再被每个请求先撞一遍。
- 修复 idleReader 竞态 —— 看门狗按「距上一个字节的空闲窗口」判定，字节在窗口边缘到达不再被误杀成 504 静默。
- 优化 日志脱敏与内存 —— 日志/错误回显里出口凭据的 userinfo 掩码；流式缓冲初始分配 1MB → 64KB（每请求省 ~1MB 急切分配）；删除无调用方的 attemptBridge 第二份状态机。

**仓库**

- `check-secrets.py` / `check-docs.py` 同步系列仓已修的守卫漏报与误报（`--all` 修复后 exit 0）；文档示例占位化、备份口径收紧、CI gofmt 修复。
